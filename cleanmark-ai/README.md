# CleanMark AI 🪄

**Remove. Restore. Export.**  
AI-powered video watermark removal with clean, natural-looking results. 

CleanMark AI is a 100% free, browser-based video inpainting tool. It leverages **WebAssembly (WASM)**, **FFmpeg**, and **OpenCV** to process videos entirely on your device—ensuring complete privacy and ₹0 API costs.

## ✨ Features
* **Zero Server Cost:** All video processing happens locally in your browser.
* **Absolute Privacy:** Your videos never leave your device.
* **Precise Selection:** Custom brush tool to select watermarks.
* **Audio Preservation:** Lossless audio stream copying via FFmpeg.
* **Premium UI:** Dark, modern, and responsive design built with Tailwind CSS.

## 🚀 Tech Stack
* **Framework:** Next.js (App Router), React, TypeScript
* **Styling:** Tailwind CSS, Lucide Icons
* **Video Processing:** FFmpeg WASM (`@ffmpeg/ffmpeg`)
* **AI Inpainting:** OpenCV.js (`cv.INPAINT_TELEA`)
